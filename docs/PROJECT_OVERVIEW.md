# ScholarLens 项目说明

## 1. 项目定位

ScholarLens 是给学生和科研人员使用的科研论文精读与可信问答工具。用户上传一篇或多篇论文后，可以围绕论文方法、数据集、实验结果和局限性提问，并查看支持回答的原始证据。

## 2. 要解决的问题

通用聊天模型可以总结论文，但经常无法证明结论来自哪里；普通文档 RAG 又往往只返回无结构的文本片段。ScholarLens 希望把科研论文的章节、页码、实验实体和回答引用连接起来，使问答结果可以验证、比较和复现。

## 3. 目标用户

- 需要快速精读论文的本科生和研究生。
- 进行文献调研、方法比较和实验复现的科研人员。
- 希望从限定论文集合中获取可追溯答案的技术从业者。

反画像：需要自动撰写完整论文、绕过论文版权限制，或要求系统替代领域专家作出高风险决策的用户。

## 4. MVP 范围

### 必须完成

1. 上传并解析科研 PDF。
2. 保留论文、章节、页码与 Chunk 的对应关系。
3. 限定在用户选择的论文集合内检索和回答。
4. 回答附带可定位的原文证据。
5. 使用固定问答集评测检索质量与引用质量。

### 暂不包含

- 自动抓取付费或受限论文全文。
- 多 Agent 自动撰写长篇综述。
- 长期用户记忆与多人协作。
- 知识图谱和复杂权限系统。
- 模型微调。

## 5. 当前技术基线

- PDF 提取：PyMuPDF4LLM + 可选 VLM 精确解析。
- 切分：标题递归切分、页面边界和跨页桥接。
- 向量存储：Milvus。
- 检索：Dense Top-K + 相似度阈值。
- 生成：OpenAI-compatible Chat Completions API。
- 重排序：后端支持 Jina、GTE 和 BGE 类型接口，但默认未启用。
- 前端：React + TypeScript + Vite。

## 6. 计划中的 ScholarLens 增强

### P0：可信引用

- 定义科研 Chunk 元数据契约。
- 回答引用到论文、章节、页码和原文片段。
- 证据不足时拒绝生成无依据结论。

### P1：混合检索与评测

- 建立 Dense 基线。
- 启用 Reranker 并完成消融实验。
- 增加 BM25 和 RRF。
- 评测 Recall@K、MRR、nDCG、引用准确率、P50/P95 延迟。

### P2：多论文比较

- 抽取研究问题、方法、数据集、Baseline、指标、结果和局限性。
- 生成带证据的论文对比矩阵。

## 7. MVP 成功标准

- 上传至少 5 篇科研论文并完成索引。
- 评测问题的正确证据能够进入 Top-5，结果可重复记录。
- 每个事实性回答至少包含一个有效引用。
- 无证据问题能够明确拒答。
- README 中提供可复现启动步骤、架构说明和真实评测结果。

## 8. 作品集呈现原则

- 清楚区分继承的基础能力和自主开发的 ScholarLens 功能。
- 简历只陈述已经实现并经过测试的结果。
- 所有检索指标使用自己的评测集重新测量，不复用其他项目的数据。
- 展示架构选择、消融实验、失败案例和改进过程，而不只展示界面截图。

## 9. 开放问题

- 第一版是否只支持英文论文，还是同时保证中英文论文效果？
- 引用定位采用页码跳转，还是进一步实现 PDF 文本高亮？
- 多论文对比优先覆盖计算机科学论文，还是保持领域无关？
- Reranker 使用云 API 还是本地模型？
