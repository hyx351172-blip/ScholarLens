## 首错诊断：所有 ID 合法，但选择了 4 个

样本：`REGRESSION-B01-C001`，BERT 的第一个预训练任务。
原始响应位置：`checks.content.evidence_ids`。
离线重现错误：`invalid_selected_evidence_ids`。

```json
["S4:U0004", "S7:U0012", "S8:U0001", "S8:U0002"]
```

该断言原本允许模型看到 **5 个 selected anchors**；上述 **4 个 ID 全部属于该集合，且没有重复**。
scope 选择 1 个、conditions 选择 3 个，也都合法。失败原因是 v3 延用了旧引文协议的
**每项最多 3 个**限制，而不是模型编造 ID、添加邻接证据、修改原文、API Key 或输出截断。

本次保持原协议和 ERROR 记录：没有偷偷截取前 3 个、忽略失败项、重新发送请求或回写旧结果。

后续工程改进建议：独立新版本中，将 ID 数量上限对齐当前合法 selected anchors 的数量
（基础包最多 8 个），继续严格限制成员资格和去重。这样不扩大已提供证据范围，
也不再沿用为长 quote 设定的固定数量上限。先覆盖 4–8 个有效 ID、越界/重复/陌生 ID 的测试，
再用本次保存响应做明确标注的离线验证；不把离线适配冒充新版本实测。

## 语义问题的离线阅读

以下是助手对保存的原文和理由的分析，不是人工裁决；human_verdict 仍为 null。

1. **SF-415：比较对象仍被误读。** content 理由正确写出 RR=4.20 是 >39 与 <34 reproductive years，
   随后却说它表示相对于非携带者的风险；scope 也混用比较对象。
   conditions 则因断言缺少生殖期/自然绝经条件而判 missing。
   引用 ID 正确不能修复这种数值关系解读；不能简单放宽条件就把整条视为可靠支持。
2. **SF-525：此次 scope 已是 entailed。** 不能继续说这次仍是“范围检查”造成误拒。
   实际阻断来自 content/conditions 对 recruitment、transient decrease 的支持要求。
   需要明确项目允许何种领域推断，再讨论与原数据集 Gold 的口径差异；不因 Gold 为 SUPPORT 就删掉核对。
3. **SF-847：单例概括已被阻断，但条件要求仍可疑。** 模型还将 MALDI 检测方法、实验设施等背景
   列为可能遗漏条件；这些是否真正改变断言适用范围应独立校准，而不能要求每条科学结论重复全部方法细节。
