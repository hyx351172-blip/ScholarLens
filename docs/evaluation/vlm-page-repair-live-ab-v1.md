## 评测边界

本次复用既有 Docling 完整解析产物，只对候选页运行 VLM 修复。自动指标衡量标题、摘要以及
Table/Figure Caption 关系覆盖，不评测正文转录、表格单元格、公式内容、跨页 Caption 或空白页 OCR。
语义正确性通过人工核对页面现有 Block 文本与被接受的关系完成。

## 人工语义复核

- 8/8 条已接受修复与原页面及 Block 文本一致，包括 1 条摘要恢复和 7 条 Table Caption 绑定。
- Llama 3 恢复的摘要是第一页真实摘要正文；Table 1、Table 2 的表号和标题均匹配。
- DeepSeek-R1 的 Table 3、Table 4、Table 5 均绑定到同页同编号 Caption。
- GPT-3 的 Table C.1、Table D.1 均绑定到对应表格说明文本。
- 3 条拒绝属于预期安全行为：模型建议替换已有且正常的标题/摘要，校验器保留了原值。

因此，本轮小样本中已接受建议的人工精确率为 8/8。该样本量不足以代表总体准确率，也不能据此
宣称 VLM 修复达到 100% 精确率。

## 暴露的问题

本轮没有实际评测 Figure 修复。候选页当前按“第一页 → 未绑定表格页 → 未绑定 Figure 页”排序，
每篇 3 页配额被摘要和表格占满。后续应按缺陷类型分层分配候选页配额，并单独建立 Figure Caption
人工标注集。
