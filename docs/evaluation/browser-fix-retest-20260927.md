- S1：Attention 第 3 页，`3 Model Architecture > 3.1 Encoder and Decoder Stacks`，正文包含编码器/解码器层及掩码说明。
- S10：BERT 第 3 页，`3 BERT`，正文直接描述 `multi-layer bidirectional Transformer encoder`，并对比 GPT 的单向注意力。

剩余问题：回答额外写了“该双向性使其适用于预训练任务如掩码语言建模，且在下游任务中通常以编码器输出作为特征输入”，仍统一引用 S10。S10 包含架构、双向性与 fine-tuning 介绍，却未完整支持这整句扩展。此处记为证据充分性保留项，不能因文档选对就声称逐句支持全部通过。
