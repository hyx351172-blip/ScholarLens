- 串行单次调用，SDK retries=0，单题外层 deadline=60 秒；错误即停，不自动续跑。
- 请求与离线冻结版本完全一致，沿用 `selected_claim_support_v1` 策略和 `fixed_v1` 输入。

- 不重新生成答案，不重新解析/检索，不调用第二个模型做评审，不启用生产门控。

## 4 个分歧案例：AI 阅读原文后的分析

下列内容是本助手结合保存的原文与 rationale 所作分析，**不是新增模型评审，也不是人工复核**。
保留全部原始标签和 30 题分母，未删除题目或事后调分。

| 样本 | 冻结标签 → 模型 | 主要问题 |
| --- | --- | --- |
| SF-847-16787954 | CONTRADICT → SUPPORT | **错误放行**：以单个药物的例子支持“新药通常如此”的总体概括 |
| SF-852-13843341 | CONTRADICT → NEI | 模型认为断言增加了摘要未描述的前置条件，未把一般性有效结论视作对该条件句的反驳 |
| SF-452-464511 | CONTRADICT → NEI | Gold 用表型差异反驳基因表达不变；模型不接受从表型差异到表达差异的推断 |
| SF-354-8774475 | NEI → CONTRADICT | evidence 为空，但候选摘要有与断言方向相反的文字；需要人工检查标注/适配歧义 |

### 优先修复：847 的量词与范围扩大

断言概括“新药通常无法以高浓度进入某类病变区域”。摘要讨论不同药物的不同表现：
有的能够进入/累积，也有一个例子扩散较差。模型把后者这一单例当作足以支持“通常”，
其理由甚至明确把一个 exemplar 当作对 generalization 的支持。

无论人工最终认可 CONTRADICT 还是更保守的 NEI，**一个例子都不足以确立这里的频率与范围概括**，
因此当前 supported 决定存在明确的证据支持缺口。核验提示词已有研究范围限制，仍未约束住模型。
这与旧 LoRA/BERT 回归中“局部结果被扩大为默认/一般结论”的风险相近，但不是同一组可直接比较的测试。

### 不应盲目调模型去迎合另外三条标签

- 852 的原断言含“对常规治疗反应不足时”这一限定，Gold rationale 主要是总体效果。
  固定策略要求逐项保留条件，因此这里可能同时包含数据集推断口径与项目严格口径的差异。
- 452 的 Gold rationale 是遗传相同细胞可呈现不同表型；模型要求更直接的基因表达证据。
  应人工确定科研推断允许到什么程度，而不是简单把拒绝推断视为门控漏洞。
- 354 的原断言是下调及错位 Scribble 可阻止转化与肿瘤形成；提供的摘要却叙述其促进方向。
  本次 NEI 是按原始 `evidence={}` 与候选引用映射而来。该记录值得优先核对，不能仅据“无标注”
  宣称原文确实没有反驳，也不能由本助手直接改成 CONTRADICT 提高分数。

## 结论边界

这是 30 题均衡 dev 子集，长摘要与不兼容断言已在模型调用前排除。
不可当作自然类别分布、未见 test set 或生产流量的效果。SciFact 的生物医学场景
与原有 LoRA/BERT 22 条科研参数/公式回归不同，两者不能直接作为方法 A/B 对比。
公开数据可能存在预训练污染；数据集分数和项目人工复核是不同层次，不能相互替代。
本轮不会因模型与 Gold 有分歧而更改标签或删除题目。
