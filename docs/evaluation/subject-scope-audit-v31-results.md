## 尚未解决的问题

### 1. 产品引用覆盖缺口仍存在

- **A01-C003**：断言不含循环或卷积，但自身只引用 S2/S3；直接说明这一点的 S8 属于别的单元。补主语后仍为 uncertain，不能借用兄弟单元的引用救援。
- **X01-C013**：S10 没有直接支持“通常仅添加轻量级分类头”。本轮改判 `unsupported / not_in_evidence`。更新全部参数与添加分类头是两个维度，不应混为一谈；引用不足的核心问题仍成立。
- **B01-C001**：列表引导句无自身引用，本地判不支持。应明确引导句引用政策，或在生成时给出直接引用；不能把这种政策问题当作事实幻觉。

### 2. 有些“支持”仍有明显评审疑点

- **L01-C008**：证据限定的是“本研究只适配注意力权重”，原回答扩展成“LoRA 通常仅应用于注意力权重”。模型仍接受这种泛化，新提示词没有可靠约束它。
- **X01-C011**：实际引用 S10 比较 BERT 与 GPT，模型理由却借用了片段外关于原始 Transformer 解码器的常识。即使科学结论本身可能成立，也不满足当前逐条引用证据约束。
- **A03-C002/C003**：理由会把压平的 `1 √ d k` 重写成分式。C003 自身还有 S3 明确写除以根号，故不能简单判整条错误；但模型选中的 S1 锚点不如 S3 充分。需要区分完整引用支持、选中锚点支持与理由是否忠实。
- **A03-C005**：“该问题”涉及前文事件/问题指代，不能靠名词主语提示覆盖所有情况。模型将它解释为小梯度问题，而紧邻前句讨论与加性注意力的性能比较，需复核。

### 3. 不支持也可能是评审误判

**X02-C006** 被判 `unsupported / contradicted`。评审用“可将 LoRA 应用于其他矩阵”反驳“冻结原始预训练权重”，疑似混淆：对一个矩阵应用低秩更新，不等于解冻该矩阵的原始权重。自身 S2:E0003 明确说冻结预训练模型权重。

对于 LayerNorm 的特指和陈述范围仍可复核，但不应未经人工检查就把模型的 contradicted 标签当作论文存在反例，也不应据此盲目修改正确的产品答案。

### 4. 行内分式损坏诱发冗长评审并截断

**L03-C009** 的断言含 `α/r`，引用文本仍是 `α r`。模型长理由在常识与严格证据约束之间反复，达到 1000 输出 tokens 后截断，JSON 未闭合，`finish_reason=length`。

本轮将其保留为 **error**，没有从残缺响应中挑一个判定，也没有提高上限后重试。证据中的分式问题与评审输出长度问题应分别处理；仅提高 token 上限不保证语义可靠。

上述判断是 AI 定向复核草稿，非独立人工标注。未声称完整复核所有 80 条支持结果，未计算“人工修正后准确率”。
