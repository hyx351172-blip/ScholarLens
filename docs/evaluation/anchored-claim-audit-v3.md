# 主语保留与证据锚点评测 v3

日期：2026-09-26。状态：**实现及离线验证完成，未执行外部评审，无新增语义成绩。**

## 本轮做了什么

在独立评测模块中修复 v2 暴露的两个工程问题：拆句后主语缺失，以及模型复写原文导致摘录校验失败。生产解析、切分、检索、回答和前端均未改动；历史原答案、v1/v2 判定和评分未覆盖，未提交或推送。

### 1. 保留可追溯的主语提示

不重写结论，不把父段落重新塞给模型。只从**同一句中此前的分句**抽取名词/符号片段，记录它在原回答里的字符位置和来源单元。

| 单元 | 原结论 | 单独提供的主语提示 | 引用范围 |
| --- | --- | --- | --- |
| L03-C004 | 不参与梯度更新 | `W_0`，原回答 139:142 | 仍是 S1、S3 |
| X01-C003 | 每层含多头自注意力与前馈网络两个子层 | 编码器，81:84 | 仍是 S1 |
| X01-C008 | 不包含解码器部分 | BERT，250:254 | 仍是 S10 |
| X01-C013 | 且其下游任务适配时通常仅添加轻量级分类头 | BERT，441:445 | 仍是 S10 |
| A01-C003 | 不含循环或卷积组件 | Transformer 模型，35:49 | 仍是 S2、S3，不增加 S8 |

位置采用 Python Unicode 字符索引，左闭右开。提示只是用于理解省略的主语，**不是结论的事实证据**。例如 X01-C013 获得 BERT 主语后，分类头细节仍须由 S10 本身支持；不能因为主语补齐就判定支持。

规则会在句号、换行、新主语处重置；无法辨认的新主语不沿用旧值。数学多主语等无法安全选择的情况不强行推断。对“论文提出某模型”的形式提取模型名词，避免将后续模型结构错误地归给“论文”这个主语。这仍是有边界的启发式，不是通用中文句法/指代模型。

### 2. 模型选择编号，程序还原原文

每个实际引用片段被无损分成锚点，例如 `S1:E0001`。每个锚点包含来源编号、起止字符位置、精确原文及是否被强制切开的标记。

- 该来源的所有锚点按顺序拼接后，必须等于原始引用文本，保留空格、换行、公式及 `[MASK]` 等内容。
- 默认每段最多 480 字符，优先沿自然句界和换行切分；超长内容必须切断时显式标记，不静默丢弃。
- 模型只返回 `evidence_ids`，不再返回自己抄写的引用文字。
- 程序校验编号属于当前结论的证据集合，再还原原文与坐标。未知、外来或重复编号，以及支持判定没有编号，都拒绝。
- 请求中仍只有一个结论、主语提示和它自己的引用，没有其他结论的证据。

这消除了“必须让模型逐字复写原文”这个步骤，**不保证模型选择的片段在语义上正确**。原解析文本中的 `α r` 仍然不等于可靠保留了 `α/r`；本轮没有修复 PDF 或检索文本。

### 3. 明确判定原因与失败边界

结构化响应新增 `reason_code`：

| 判定 | 允许原因 |
| --- | --- |
| supported | entailed |
| unsupported | contradicted、not_in_evidence；本地无引用使用 no_valid_citation |
| uncertain | ambiguous_subject、ambiguous_evidence |

如果模型给出“主语不明”原因却把判定枚举写成不支持，本地校验拒绝这组不一致字段，而不是自动改分。模型理由本身是否正确仍需要复核。

提示词另外明确：区分“理论上可以”与“已做实验”、研究范围与一般惯例、局部结论支持与完整回答覆盖；残缺数学证据不能自行补乘号或除号。这些是待线上验证的约束，不宣称仅凭改提示词就解决所有语义误判。
