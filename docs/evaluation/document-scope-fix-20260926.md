# 多论文验收：文档范围约束修复与复测

日期：2026-09-26。范围：开发集回归，不是新的 held-out 评测。

## 结论

此前多论文验收中，A04、B04、L02 的回答虽然拒答或包含正确核心事实，候选证据仍混入了非目标论文。修复后，同一批 16 道题的在线检索、回答、来源校验全部满足原有机械验收规则，由 **13/16 提升到 16/16**，没有删题、改题或降低门槛。

这里的“通过”指文档范围、引用 ID、原文与页码一致性等契约；不能解读为回答的每个语义断言均正确，也不能宣称泛化准确率 100%。

## 修复内容

- 从当前知识库目录解析当前问题中的论文名称，优先生成精确 `file_id` 过滤条件；旧目录没有 ID 时才使用转义后的文件名。
- 用户指定的范围约束原始问题、规划子问题、失败回退和返回候选；检索端推下过滤条件后，应用层再次校验，防止上游忽略过滤。
- 单篇论文问题直接跳过跨论文规划，避免把 LoRA 摘要中的 Adam/GPT-3 比较对象误当成第二篇目标论文。
- 真正的两篇论文比较保留两篇联合范围，每个子查询再缩小到对应论文。
- 当前问题中的明确切换指令优先，否定的上一轮论文提及不扩大范围。
- 显式指定的论文不存在或别名不唯一时停止检索并记录原因；目录服务错误返回 503，而不是悄悄进行全库检索。
- “根据这些论文……”等泛指语句仍属于知识库范围，不误报为未知论文；格式错误的目录行不能被静默忽略成空目录。

主要实现：`backend/chat/document_scope.py`、`backend/chat/kb_chat.py`。

## 固定实验条件

- 复用上次真实上传的 Attention、BERT、LoRA 三篇论文，共 57 页、205 个 chunks。
- 复用混合知识库 `kb_1790422371399` 和空知识库 `kb_1790422372333`，不重新上传、解析、切分或入库。
- 题目、预期、检查器与上次一致；包含 12 道可回答题、3 道论文中无答案题、1 道空库题，其中 2 道跨论文比较、1 道历史切换。
- 模型 `qwen3-vl-plus`，temperature 0，max_tokens 1000；Top-K 10，阈值 0.1，多查询开启，Reranker 关闭。
- 使用隔离 Chat 服务 8502；没有重启原始 8501 服务。本轮没有重新验收上传或浏览器操作。
- 在线复跑仅执行一次，不自动重试或挑选最好结果；未调用付费 judge。

## 已知边界与后续

- 文档匹配基于文件名及目录可选标题的确定性别名；不保证识别任意中文译名、意译或“它/上一篇”等指代。
- 这是一项检索范围约束，不是用户权限隔离功能。
- 别名冲突、未找到显式论文时已安全停止，但前端尚无专门的澄清选择交互。
- 多数测试复用已用于开发的三篇论文；不能作为新测试集上的无偏泛化指标。
- 返回来源与原文一致，不等于回答的每个扩展断言都被对应引用支持。下一项质量验收应聚焦逐断言证据支持，不继续把机械契约通过率称为回答正确率。
- 本轮按技能要求采用失败用例→修复→回归，保留失败基线和版本记录；未提交、合并或推送。
