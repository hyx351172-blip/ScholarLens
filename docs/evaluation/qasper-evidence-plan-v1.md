# 证据规划对照实验 v1

日期：2026-09-26。按 ai-product-dev-pack 流程先固定测试与验收范围，再实现单特性实验。正式聊天没有启用规划模块。

## 方案与边界

新增 `backend/chat/evidence_plan.py`：一次额外模型调用提取可能的指代对象、来源编号、逐字摘录；校验后作为低信任用户消息辅助回答。原始全文仍保留，原有 guard v2 不变。计划不能更改系统指令，不能生成新来源，不能把不相关摘录变成事实依据。

确定性校验只保留真实来源中的连续摘录，最多 8 个候选，摘录最多 1,200 字符；重复摘录丢弃。结构错误和虚构摘录返回空计划，最终回答仍查看全文。原文存在不等于相关或蕴含，后者没有被本校验解决。

20 题与 `qasper-guard-validation-v1` 完全相同，使用同一模型、temperature=0；不读取标签生成答案。该批次现在是**开发集**，不能再声称是独立验证集。基线是上一轮固定结果而非同期多次重复实验，存在模型生成波动，不能单独归因所有变化。

冻结配置和数据在 `output/qasper-evidence-plan-v1/manifest.json`。每题保存规划原始输出、通过校验的候选、回答原始输出、最终输出、两次调用的 token 使用量。生成脚本校验输入、防护与规划模块哈希。

## 关键案例复核

- `prediction-05.json`：规划正确找到 353 段会话、40 名说话者的 S14，同时找到模拟数据集 S40；最终回答仍将目标限定为模拟数据集而拒绝给出大小。**定位成功但答案选择失败**。guard 返回 passed，是因为该英文拒答表达未被现有启发式完整识别，不是该题已经答对。
- `prediction-07.json`：规划找到实验结果及总结。模型将 realistic 扩展成部署、规模化与可用性等未在问题明确指定的标准，最终仍拒答；没有达到数据集参考 Yes 的预期。不能靠强迫所有评价问题回答 Yes 修复。
- `prediction-00.json`：回答实际承认缺少预训练数据来源，但 fixed-abstention 计数未捕获这一拒答句式。固定拒答率下降不能直接解释为无答案幻觉增多或误拒答减少。

## 复现

```powershell
python tests/integration/prepare_evidence_plan_experiment.py
python tests/integration/run_qasper_guard.py --output-dir output/qasper-evidence-plan-v1
python tests/integration/score_qasper_guard.py --output-dir output/qasper-evidence-plan-v1
python tests/integration/compare_evidence_plan.py
```

准备脚本拒绝覆盖；重新生成新实验需要新的目录。单轮上限 40 次调用，无自动网络重试。模型错误会中止而非补造结果。

## 当前判定

本实验不能仅凭通过的引用格式或更少的固定拒答宣布有效。两个目标失败题仍未解决，暂不接入正式聊天。后续应评估结构化“候选对象→答案→依据”输出及可回答性人工复核，而不是继续扩大拒答正则或自动升级所有回答为双调用。

## 完整结果

40 次调用完成，20/20 题产物齐全；回答及规划均无长度截断，1 题校验后候选为空。

| 指标 | 固定基线 | 证据规划实验 |
| --- | --- | --- |
| 可回答题固定拒答 | 2/15 | 1/15 |
| 无答案题固定拒答 | 4/5 | 3/5 |
| 可回答题最终 token F1 | 0.24855 | 0.25397 |
| 平均每题耗时 | 4.17 秒 | 17.16 秒 |
| 总 tokens | 98,753 | 216,097 |

实验输入 203,957 tokens，输出 12,140 tokens。耗时约为基线 4.12 倍，tokens 约 2.19 倍；不等同于实际账单倍数。

固定拒答变化只发生在上文的 00 和 05 两题，二者实际仍然表达无法回答。因此不能把 2/15→1/15 当作修复一题的证据。F1 微升也不能视为语义效果提升，尚未逐题作完整事实/蕴含审计。

工程结果：新增校验测试 7 项；完整回归 420 项通过（19.245 秒），114 条 AC 可追溯检查通过，`git diff --check` 通过。外部 API 契约没有改变。实验代码可继续开发，但功能默认上线判定为 **no-go**：目标问题未解决且额外成本明显。未提交、推送或重启服务。
