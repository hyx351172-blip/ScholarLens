## 三项改进

### 1. 按句子、引用边界及部分分句拆细

- 中文句号后不需要空格也能拆开；支持英文句子、分号和选定的分句逗号。
- 保留小数、`et al.` 等常见缩写、LaTeX、代码中的标点，以及 `[MASK]` 等非引用方括号内容。
- 排除列表序号、明确的过渡语，但保留可能包含事实的加粗文本。带事实数量的引导句不自动丢弃。
- 每个单元保留原回答中的起止位置、原始文本、引用位置和绑定规则，可逐字检查。
- 同一区域里、位于末尾引用之前的分句可以继承该组引用，记录为 `trailing_group_in_same_region`；不向前一句或下一行借引用。

这是确定性、抽取式的分句器，不是保证完美的“原子事实提取器”。当前仍标记 28 个可能依赖上下文的单元、39 个可能包含复合陈述的单元，两类可以重叠。数值是风险提示，不是人工确认的问题数量。

### 2. 每个请求只含一条结论和它自己的证据

旧版同一次请求中包含整份回答的多条结论；虽然提示要求不得借证据，但模型仍能看见其他单元。

新版每次请求只发送问题、当前结论 ID、当前结论文本及其引用片段。不会发送完整回答、父段落、其他结论或全局候选证据；也不复用历史对话。问题仅用于确认对象，不作为事实证据。

如果一个分句离开上下文后无法确认对象，允许评审给出 `uncertain`，不要求模型脑补主语。对残缺公式同样允许不确定，禁止把丢失分数线的文本强行解释成乘法或除法。

### 3. JSON 模式 + 严格本地验证

请求使用 JSON Object 模式，并关闭思考模式。该设置与当前模型支持范围已核对[阿里云结构化输出文档](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。JSON Object 只约束 JSON 格式，不保证字段或语义正确。

本地要求字段恰好是 `claim_id`、`verdict`、`reason`、`supporting_quotes`；判定只能为 `supported / unsupported / uncertain`。支持判定至少需要一条可在本单元引用中逐字找到的原文摘录。

下列情况都记为错误，不静默修补、不重试：坏 JSON、重复键、额外文本/字段、错误结论 ID、假造摘录、引用其他单元的来源、输出截断、供应商拒绝或请求失败。摘录能定位只证明出处合法，不自动证明它蕴含该结论。

## 冻结样本上的本地准备结果

仍复用原始 16 份回答，其中 12 份有实质答案、4 份固定拒答：

| 检查项 | 结果 |
| --- | --- |
| v1 句子/复合单元 | 35 |
| v2 较小单元 | 85 |
| 有引用、需要单独模型评审 | 84 |
| 无有效引用、可本地判为不支持 | 1 |
| 固定拒答 | 4，不放入结论支持率分母 |

唯一无引用单元是 B01 开头的“BERT 使用两个预训练任务”。它是带有事实数量的引导句；现行严格逐句规则不把后续列表的引用自动借给它。这个结果不是宣称 BERT 只有两个任务的说法有事实错误，人工可以复核这种引用范围政策是否适合产品。

重点拆分检查：

- **A01-C003**：“不含循环或卷积组件”单独成条，只绑定 S2/S3，不再看到其他结论使用的 S8。
- **X01-C013**：“下游任务适配时通常仅添加轻量级分类头”单独成条，仅带 S10，不再和编码器主干描述一起判通过。
- **L03-C009**：`alpha/r` 与后续 alpha 的取值说明分开，评审可以明确表达分式证据有歧义。

35 → 85 是统计粒度变化，答案完全没变，不能解读为回答准确率或召回效果提升。

## 文件与使用

- 核心实现：`tests/integration/isolated_claim_audit.py`
- 准备/运行入口：`tests/integration/evaluate_multipaper_claims_v2.py`
- 回归测试：`tests/test_isolated_claim_audit.py`
- 最终评测包：`output/e2e-claim-audit-v2-final/`
- `inputs.json`：85 个带来源范围与字符位置的单元。
- `evidence-*.md`：按题阅读的结论、原文与页码。
- `segmentation.json`：拆分前后数量及风险提示。
- `manifest.json`：输入/实现/v1 产物哈希与计划调用数量。
- `human-review.json`：边界、引用绑定与语义判断均待人工确认。

```powershell
python -X utf8 -m unittest tests.test_isolated_claim_audit
# 已生成的包不可覆盖，prepare 只能用于不存在的版本化输出目录。
python -X utf8 tests/integration/evaluate_multipaper_claims_v2.py prepare
# 以下会新增 API 费用；需要用户明确授权本批 84 次调用后执行。
python -X utf8 tests/integration/evaluate_multipaper_claims_v2.py run --max-calls 84
```

在线执行将保留每次调用的原始文本、用量、结束原因和错误；自动重试为 0，不自动退回普通文本格式。尚未确认完成的调用有独占标记，恢复时不会自动重复计费。错误、未执行和不确定分别统计，不从总分母删除；只有全部单元获得支持才会通过严格语义门。
