## Held-out 边界

这不是论文级全新测试集。当前 19 篇语料中，10 篇已经用于 v3 开发集，
另有 2 篇文件名与正文不匹配；剩余 7 篇都曾出现在已消耗的 v2 中。因此
v4 的隔离单位是“新问题 + 过去未作为 Gold 的 chunk 组合”。8 个问题与
v1/v2/v3 均无完全相同的问题，16 个 Gold chunk ID 也与三个旧数据集完全
不重叠。

Gold 是直接阅读 Milvus 中的 chunk 后选定的，没有用当前语义检索器挑选，
避免把检索器偏好写回测试集。
