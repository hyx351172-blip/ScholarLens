## ⚠️ 使用变化与未完成项

- `use_multi_query=false` 仍关闭 LLM 规划，但明确命名的多论文问题会做“原问题 + 每篇过滤检索”，最多 4 路查询。这可能增加查询 Embedding 的费用；单论文查询行为保留。
- 目前只处理目录中可明确解析的 2–3 篇论文；未命名的“比较这些论文”仍不属于本次确定性覆盖保证。超过 3 篇或 Top-K 无法容纳时拒答。
- 只保留历史用户问题，依赖上一轮助手细节的模糊追问可能需要用户补充论文/对象名。这是减少历史断言污染的保守取舍。
- 当前保护不能替代逐断言语义核验。即使覆盖两篇，仍需要真实模型复测确认具体比较答案的引用是否正确。
- 原文 PDF 链接的文件/页码未改动；内嵌浏览器 PDF 预览仍待普通 Chrome/Edge 核验。
- 旧会话答案不会自动重算。修复作用于后续新提问；此次只是用旧答案验证新的渲染器，没有把旧错误答案标成已修正。
