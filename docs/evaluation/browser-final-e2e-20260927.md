## ⚠️ 失败项与待核验项

### 跨论文证据覆盖和引用归属：优先修复

X01 要求同时比较两篇论文，但本轮证据列表的 6 个已引用片段及 4 个未引用候选均属于 Attention。回答仍输出 BERT encoder-only、MLM/NSP 等内容，将其附在当前轮 S4/S7/S8 上，随后又声明 BERT 细节证据不足。

S4 抽屉显示：Attention，PDF p3，`3 Model Architecture`，Figure 1 的 Transformer encoder-decoder 描述。它不是 BERT 证据。结论听起来合理、引用按钮可以点击，都不能抵消引用错配。

已确认的是**目标论文覆盖不足和回答引用不能支持相关结论**，未在本轮定位最终代码根因。历史消息的局部 S 编号复用、目标论文范围识别及跨论文检索路径均值得排查，但不能把这些假设写成已证实原因。此前 API 实验和当前 UI 默认多查询参数不同，也尚未进行受控 A/B 来证明因果关系。

### 公式渲染：内容通过不等于显示通过

A03 原始 LaTeX 公式被直接显示，包含 `$$`、`\frac`、`\sqrt`；A01 的部分行内公式也显示源码。后续应验证数学渲染与可点击引用的共存，避免将公式内部的引用标记破坏为普通文本。此轮只记录，未修改前端。

### 窄屏操作：知识库选择入口缺失

初始内嵌浏览器窄视口下，科研问答页没有可见知识库选择器。为完成指定隔离库测试，临时使用 1440 × 1000 桌面视口，结束后已恢复。代码中知识库选择使用 `hidden sm:block`、会话侧栏使用 `hidden ... xl:flex`，对应窄屏下选择库及新建会话入口的可用性风险；本轮没有看到替代入口。

### 原文 PDF 跳转：链接通过，页面渲染待核验

A02 实际激活“打开原文 PDF”，打开的地址为：

```text
http://localhost:8000/document/file_20260927_fd0fd2ca/pdf#page=8
```

文件及页码片段正确，但 Codex 内嵌浏览器显示灰色失败视图，没有显示 PDF 页面。当前自动化环境没有可用 Chrome，无法在另一浏览器复核。只读 API 下载内容的哈希与原 PDF 一致，本地原文页面也能渲染；这些仅证明文件有效，**不能替代浏览器真实显示和页码定位验收**。需在普通 Chrome/Edge 复核，暂不归因为后端文件损坏或确定的前端缺陷。

其他观察：A02 表格抽屉的章节路径显示 `5 Training > 5.4 Regularization`，但表格回答及页码正确；本轮未对所有章节路径做系统评分。
