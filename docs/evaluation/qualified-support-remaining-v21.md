## 首错诊断：省略号不是空白差异

失败样本：`SCIFACT-SF-415-6309659`。
位置：原始 JSON 的 `checks.conditions.citations[1]`，锚点 `S1:E0006`。
离线复现的具体异常为 **`missing_quote`**。

模型把连续原文的一段数值和比较条件删掉，在 quote 内自行插入了 `[...]`：

```text
... APOE epsilon4 carriers [...] whereas in noncarriers ...
```

原文在该处包含 reproductive years 的比较、RR 和置信区间，没有 `[...]`。
本条其他 3 个引用能精确匹配；失败引用不是换行/空格差异，因此受限空白修复不应放行。
响应是完整 JSON、finish_reason=stop、无 API 拒绝或截断，故不是 API Key、超时或输出长度问题。

此次 4 个结构有效响应共 12 个引用均为 exact，本次没有触发 whitespace_only 修复。
上一条历史响应的空白修复成功仍单列于 historical_replay，不能用于虚增本次成功数。

本次未删除失败引用、未自动拼接省略部分、未修改原始响应或旧实验结果。
即使该引用来自 missing 检查项，也不能让无效出处悄悄进入已验证结果。

## 次要发现：范围与条件检查可能过严

以下是助手对已保存证据的初步阅读，**不是用户人工裁决，也不修改 Gold**。

SF-525 在 v1 中为 SUPPORT，本次变成 NEI：模型把普通类别陈述进一步要求为对“所有”核受体
均成立，并要求摘要写出 loss-of-function/rescue 实验细节才能认可 necessity。
但锚点 E0002 明确称为 general strategy，E0003 明确使用 requirement。
这些额外要求值得校准；另一方面，断言中的 recruitment 和 transient decrease 在选定摘要中的
支持边界仍需复核，不能只删掉范围检查便宣称整条已正确。

SF-415 的原始理由还将 RR=4.20 解释为携带者与非携带者的风险比较；
引用原文本身的比较实际是 APOE ε4 携带者中不同 reproductive years 组。
该条目前因引文无效而没有正式语义 verdict，但这也说明“出处有效”不等于“解释正确”。
