# 完整句级证据：小规模真实生成复测 v1

日期：2026-09-27。当前状态：**已获用户同意并完成 5 次真实生成、1 道本地空库对照。**

## 结论

**暂不默认启用 sentence_v2。** 4 道正例均有合法结构与引用、2 道负例均拒答，但人工待复核的
关键语义问题仍存在：遗漏维度依据、补写模糊分式、把研究范围推广为默认设置。
完整句解决了原文被切断的问题，没有使模型自动选齐必要证据或保留全部限定条件。

本次 5 次调用合计 **55,839 token**，相比同 5 题的历史 fixed_v1 新模式用量 28,687 token
高 94.65%。这是不同时间、各一次生成的描述性对照，不是同期随机配对 A/B，不能据此推断
稳定的性能或费用涨幅；本报告不虚构人民币账单。

## 逐条证据检查（AI 草稿，非人工 Gold）

### 有所改善，但应限定解释

- B01 只回答 MLM 与 NSP 两个任务，不再附加“以 50% 概率判断”的有歧义描述，所选原文包含
  Task #1 / Task #2。问题本来只问任务名称，因此简洁回答是合适的；但模型没有再次解释比例，
  不能宣称已证明它能够正确回答 50% 的含义。
- L01-C007 现在选中了完整条件句 S1:U0010，不再只绑定半句。但生成文字仍漏掉
  “applying LoRA to all weight matrices”，说明源句完整不等于输出限定条件完整。

### 原有问题仍在

| 案例/结论 | 选中的依据 | 未被充分支持的内容 |
| --- | --- | --- |
| L03-C002 | S1:U0011、S2:U0002，只有初始化句 | 回答同时写了 A、B 的维度，未选择包含维度的单元 |
| L01-C005 / L03-C003 | 原文仍是压平的 α r | 回答仍补成 α/r；本批检索文字没有清晰保留除号 |
| X02-C003 | S3:U0004：“We limit our study…” | 回答仍写“LoRA 默认仅适配”，把研究设置扩大为方法默认 |

分式在论文中可能确实是除法，但这不等于本轮选中片段足以直接证明，不能用模型记忆补证。

### 更细的引用也暴露了额外缺口

- L03-C001 包含“冻结的预训练权重”，但所选公式、维度和按坐标求和单元没有冻结条件；
  冻结句在未选的 S1:U0007。不能借本题其他结论或完整 chunk 的内容算作本条引用。
- X02-C004 的维度依据存在，但“可训练参数仅为 A、B”的依据不在本条选中的 S8:U0006，
  而在其他单元；X02-C002 引过冻结/训练句，不代表 C004 自动继承它。
- L01-C006 / X02-C003 写出具体注意力矩阵示例，但所选研究范围句没有列出这些矩阵名称。
- L01-C008 从“没有额外推理延迟”写到“与全微调模型性能一致”，措辞扩大了范围；若只想表达
  延迟，应明确写延迟，不能据此声称任务效果一致。

对 L03-C005 的调参目的、X02-C005 的“仅添加任务头”等细节，保留待人工确认，未硬判为错误。
全部 22 条 AI 检查备注见 [复核草稿](evidence-units-live-v1-review.json)。它不改写原回答，
也不填充 human-review.json 的人工结论。
